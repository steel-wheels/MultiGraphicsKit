# Programming Tips

## macOS/iOS

### Metal4 support
* macOS 26.0 or newer.
* iOS 26.0 or newer.

## Coding by Swift

### <code>import</code>
To use <code>MTL4*</code> class, import following frameworks.

<pre>
import Metal            // Data processing by Metal
import MetalKit         // User interface by Metal
</pre>
